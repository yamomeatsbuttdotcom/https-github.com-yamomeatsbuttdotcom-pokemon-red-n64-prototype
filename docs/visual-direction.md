# Approved visual direction

The nine-panel concept image is reference art, not an emulator screenshot.
Aim for low-poly colorful N64-style towns, distinct rooftops, flower beds,
trees, a readable red-capped trainer, Oak's Lab starter displays, blue dialogue
panels, rocky Pewter Gym, and a blocked Mt. Moon entrance.

The renderer currently projects world cuboids isometrically using RDP triangles.
Perspective 3D, animation, detailed Pokémon meshes, and emulator verification
are still outstanding.

GitHub Actions must remain manual-only until the user approves a final build.
